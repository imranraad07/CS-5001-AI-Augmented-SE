# Local AI Setup for the Online Course

The online demos use Streamlit as the UI and Ollama as the local LLM runtime. No paid API key is required.

## 1. Install and start Ollama

Install Ollama for your operating system, then pull the default course models:

```bash
ollama pull qwen3:4b
ollama pull embeddinggemma
```

Ollama should be available at `http://localhost:11434`.

## 2. Install Python dependencies

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r Online_Course/requirements.txt
```

## 3. Run a module

Every module is independently runnable:

```bash
streamlit run Online_Course/Module_01_Crash_Course_Demo/streamlit_app.py
```

Replace the module path to run Modules 2–15.

## What is real

- LLM responses are generated by the configured Ollama model.
- Agent modules use Ollama tool calling.
- File reads/writes are performed against disposable local demo repositories.
- Test results come from real `python -m pytest -q` subprocesses.
- RAG uses Ollama embeddings and cosine similarity over project artifacts.
- Multi-agent roles are separate Ollama inference calls.
- Orchestration uses a bounded agent/retry/verification loop.
- Module 13 uses a real MCP stdio server/client session and exposes bounded repository tools.
- Module 14 constructs messages with the official A2A Python SDK data model and uses a real local specialist model. It intentionally does not claim that an in-process demonstration is a networked A2A deployment.
- Module 15 combines controlled tools, an action limit, audit records, and independent pytest verification.

## Safety boundary

Agent file operations are restricted to a temporary demo workspace. The model is not given arbitrary shell execution. The only subprocess exposed by the course tool layer is the predefined pytest command.

## Models

The defaults are `qwen3:4b` for chat/tool use and `embeddinggemma` for embeddings. The Streamlit sidebar allows the instructor to select other locally installed Ollama models.
