# Module 10: Planning and Multi-Agent Systems

This demo represents specialized **logical agents** as Python classes. They may be backed by one model or multiple models in a real system.

Run:
```bash
cd Online_Course/Module_10_Planning_Multi_Agent
python multi_agent.py
pytest -q
```

Record the plan first, then pass the artifact through coder, tester, and reviewer. Emphasize task decomposition, specialization, sequential output passing, and verification.
