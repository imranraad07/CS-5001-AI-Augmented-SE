# Module 13: MCP, Connecting Agents to Tools

**Important:** `mcp_demo.py` is a dependency-free teaching model of MCP concepts, not a conforming MCP implementation.

It demonstrates the course concepts of client/server capability discovery, tool schemas, structured parameters, and structured results.

Run:
```bash
cd Online_Course/Module_13_MCP
python mcp_demo.py
pytest -q
```

Use it to contrast RAG (retrieve knowledge), tool calling (perform actions), and MCP (standardize the tool interface). For a later production lab, replace this teaching model with the current official MCP SDK.
